VK03M & SilverStone E360MAX Dual Display Studio

專為 瓦爾基里（瓦尔基里）Valkyrie VK03M / VK03-M 機箱長條副屏 與 銀欣（银欣）SilverStone E360MAX / E360 MAX 水冷頭方形副屏 打造的開源雙屏即時監控與 Web 視覺化編輯台（http://localhost:5050），可替代官方 Myth.Cool 與 ICENODE 常駐軟體，支援模組化拖曳排版、13 種動態背景特效、中文音樂卡片與開機免 UAC 靜默自啟動。

前往 GitHub 專案原始碼 完整 README 安裝說明 問題回報 / 討論

介面實機預覽

1. 瓦爾基里 VK03M / VK03-M 機箱副屏（960×360）

3 欄 GridStack 模組化卡片、內嵌配色器、中文歌名播放卡片與 13 種程序式動態背景特效。

2. 銀欣 E360MAX / E360 MAX 水冷頭（480×480）

原生 Windows HID 免換驅動推流，支援 2×2 自由合併區塊與左右虛線指向編輯台。

核心功能特色

雙螢幕同步即時推流

同一份瀏覽器編輯介面（localhost:5050）獨立控制機箱 960×360（MS9132）與水冷頭 480×480（HWCX HID），關閉分頁自動省電跳過網頁端預覽壓縮。

13 種程序式動態背景特效

模組化 ambient_fx.py 引擎，針對副屏刷新率最佳化，支援透明度與流速微調，亦可疊加自訂背景桌布。

Windows 11 CPU 溫度與瓦數

整合 LibreHardwareMonitorLib.dll 與 WHQL 簽章 HardwareHelp64.dll，即使開啟 Win11 核心隔離（HVCI）仍可穩定讀值。

中文音樂卡與按需休眠

透過 Windows GSMTC 抓取 Spotify / 瀏覽器曲目與封面，使用微軟正黑體精準截斷不亂碼；未放音樂卡時輪詢自動休眠。

防碰撞保護與免 UAC 自啟動

自動偵測 MythCool.exe 避免搶佔 USB 介面；提供 install_autostart.bat 一鍵設定 Windows 工作排程靜默管理員啟動。

開源透明與單元測試

基於 hogancv/valkyrie-240-lcd 擴展，內含 MS9132 協議與渲染單元測試，無接硬體亦可驗證。

內建 13 種動態背景特效列表（VK03M 960×360）

波浪 Waves 星座點線 Constellation 雙重融合 Dual 極光幕簾 Aurora 等離子雲 Plasma 熔岩光球 Metaballs 駭客代碼雨 Matrix Rain 賽博網格 SynthGrid 星際躍遷 Starfield 晶片脈衝 Circuit 蜂巢脈動 HexPulse 雷達掃描 Radar 流螢光斑 Fireflies

快速安裝與啟動（Windows）

git clone https://github.com/Patch0uli/Vk03m_E360MAX-display.git
cd Vk03m_E360MAX-display
pip install -r requirements.txt
python tools/doctor.py

# 手動啟動（或直接右鍵以系統管理員身分執行 install_autostart.bat 設定開機自啟動）
python web_editor/app.py

啟動後開啟瀏覽器前往 http://localhost:5050 即可即時編輯雙螢幕。詳細硬體踩坑與協議說明請見 GitHub 專案中的 PROTOCOL.md 與 PITFALLS.md。

MS9132 硬體提醒：絕對不要對 MS9132 裝置呼叫 USB Bus Reset（usb.core.Device.reset()），否則會導致韌體鎖死出現 VID_0000&PID_0005。若不慎卡死，請以系統管理員身分執行 fix_usb.bat 或徹底切斷電源 30 秒放電。
